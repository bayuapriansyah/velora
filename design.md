# Velora Design System

Version: 2.0

---

# Product Vision

Velora is an enterprise-grade Web3 security dashboard that lets users define immutable on-chain spending policies for AI agents.

The interface should feel trustworthy, premium, and modern.

Users should immediately understand that this software protects digital assets.

Avoid consumer-app aesthetics.

Avoid startup landing page aesthetics.

Think:

- Enterprise
- Finance
- AI
- Blockchain
- Security
